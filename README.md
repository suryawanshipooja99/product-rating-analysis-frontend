# 📊 Product Rating Analysis - Frontend

## 📌 Overview
This is the frontend application for the Product Ratings & Review Analytics Dashboard.  
It provides an interactive UI to visualize product analytics and manage uploaded data.

---

## 🛠️ Tech Stack
- React.js
- Material UI (MUI)
- Redux Toolkit
- ApexCharts / Recharts

---

## ✨ Features

### 📊 Dashboard
- Products per Category (Bar Chart)
- Top Reviewed Products
- Discount Distribution (Histogram)
- Category-wise Average Rating

### 🔍 Search & Filters
- Search by product name
- Filter by category
- Filter by reviews

### 📋 Table View
- Paginated table
- Sorting and filtering

### 📥 File Upload
- Upload CSV/Excel files
- Sends data to backend API
